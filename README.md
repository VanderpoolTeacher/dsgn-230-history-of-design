## Modules

Each module folder contains a lesson (.md), an examples reference (.md), an interactive (.html), and an images/ subfolder. Naming convention for lessons: `lesson-{topic}.md`.

### Completed

- **Art Nouveau** (c. 1890–1910) — In-depth lesson covering key figures, regional variations, landmark works, and historical context. Includes an interactive with image gallery, flip cards, matching activities, and a 10-question quiz.

### In Progress

- Industrial Revolution & Early Design Reform (c. 1760–1880)
- Arts & Crafts Movement (c. 1880–1910)
- Early Modernism & the Avant-Garde (c. 1910–1930)
- Bauhaus (1919–1933)
- Art Deco (c. 1920–1940)
- Mid-Century Modern (c. 1945–1970)
- Postmodernism (c. 1970–1990)
- Digital Revolution & Contemporary Design (c. 1990–Present)
